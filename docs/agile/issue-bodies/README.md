# Body issue GitHub (generated)

File di folder ini dihasilkan dari [`../us-registry.md`](../us-registry.md).

```bash
npm run sync:github-us-issues          # regenerate file di sini
npm run sync:github-us-issues:apply    # push ke GitHub (butuh gh auth)
```

Sebelum `--apply`: `gh auth refresh -h github.com`

Salin manual: buka `US1-4-issue-5.md` (contoh) → tempel ke issue #5 di GitHub jika CLI belum login.
