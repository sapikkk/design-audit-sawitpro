① Pilih area  →  ② Mulai periksa  →  ③ Tiap baris: Perbaiki atau klik teks untuk tunjuk layer

Periksa bagian
Belum ada laporan
  • Tekan Mulai periksa.
  • Pastikan library SawitPRO sudah nyala (menu Assets).

Setiap baris punya tombol Perbaiki. Yang otomatis: Perbaiki otomatis; sisanya: Perbaiki (tunjuk layer). Atau Perbaiki semua otomatis di bawah.

Dulu: tab Periksa → Mulai periksa.

Hanya jika perlu banyak: lepas variabel atau ganti token A jadi B.

Lepas variabel

Putuskan hubungan layer dengan variabel warna/jarak.

Ganti variabel

Pada layer terpilih: variabel lama diganti variabel baru.

Komponen bertanda [no-tokens] tidak diperiksa.
